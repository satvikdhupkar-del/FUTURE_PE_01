# Prompts Used — Sawariya Mobile Shopee Website Copy

This file contains the structured, reusable prompts used to generate the website copy for **Sawariya Mobile Shopee**, a mobile phone sales/repair/accessories shop in Bibwewadi, Pune.

Tool used: **Claude (claude.ai)**

---

## 1. Master Context Prompt (used before every generation)

```
You are a professional website copywriter creating conversion-focused
copy for a local business client.

Business: Sawariya Mobile Shopee
Category: Mobile phone store — sales, repairs, accessories, Jio SIM/prepaid products
Address: Shop no 4, 658/8/6, Opp Vinayak Sweets, Upper Kondhawa Rd,
Bibwewadi, Pune, Maharashtra 411037
Phone: +91 77448 83919
Hours: Open all 7 days, 10:00 AM – 10:00 PM

Business model (critical — must be reflected clearly in all copy):
- SERVICES (repairs, diagnostics, SIM activation) are available
  ONLY in-store. No pickup/drop, no doorstep repair.
- PRODUCTS (accessories, covers, chargers, cables, screen guards, etc.)
  can be ordered and are DELIVERED anywhere across Pune.
- Never blur these two — a customer should never think they can get
  a repair done via delivery.

Tone: Friendly, confident, and simple — approachable local shop,
not a corporate electronics chain. Trustworthy and direct.

All copy must be benefit-driven, specific to a mobile shop (not
generic "we provide quality service" filler), and ready to paste
into a real website.
```

---

## 2. Homepage Copy Prompt

```
Using the business context above, write homepage copy with:
1. A headline (clear value proposition, under 10 words)
2. A sub-headline (who it's for + the core benefit, under 20 words)
3. A short intro paragraph (2-3 sentences) introducing the shop
4. Three CTA button labels for the hero section

Make the headline highlight BOTH the in-store repair trust factor
AND the Pune-wide delivery for products.
```

---

## 3. Services Page Prompt

```
Using the business context above, write Services page content for
Sawariya Mobile Shopee. For each service (Screen Repair, Battery
Replacement, Software/Diagnostics, SIM Activation & Jio Recharge),
provide:
- Service name
- One-line description of what's included
- One line on why the customer should choose this shop for it

Add a clear banner line at the top of the section stating these
services are available in-store only, with hours and a "walk-ins
welcome" note.
```

---

## 4. Products / Shop Page Prompt

```
Using the business context above, write copy for the Products page
covering accessories (mobile covers, chargers, cables, earphones,
screen guards, Jio SIM/recharge). Emphasize that these can be
ordered and delivered anywhere in Pune. Include a short line
encouraging customers to message on WhatsApp with the product they
want and their delivery address.
```

---

## 5. CTA Sections Prompt

```
Using the business context above, write three separate CTA blocks:
1. A "Book a Repair" CTA (urgency + trust-based, encourages a shop visit)
2. A "Shop Accessories" CTA (delivery-across-Pune focused)
3. A "Contact / Visit Us" CTA for the footer/location section
  (location + hours + phone number reinforcement)

Keep each CTA to 1-2 lines of supporting copy plus a button label.
```

---

## 6. Testimonial Section Prompt

```
Write a short intro line (1 sentence) for a customer testimonials
section, framed to build trust despite a mixed review history —
focus on genuine service rather than overselling.
```
